console.log('请提供用户名');

console.log(greeting);



// 返回问候语


return greeting;


}

Python 代码示例



```python


Python 示例代码


def calculate_fibonacci(n):


"""计算斐波那契数列的第n项"""


if n <= 1:


return n



a, b = 0, 1


for i in range(2, n + 1):


a, b = b, a + b



return b



测试函数


for i in range(10):


print(f"fibonacci({i}) = {calculate_fibonacci(i)}")


```
